## Как работать
- Сначала изучи только релевантные файлы и текущее состояние проекта.
- Не перечитывай весь репозиторий без причины.
- Разбей работу на небольшие законченные этапы.
- По умолчанию используй Sonnet для реализации.
- Подключай Opus только для сложных архитектурных, security- и debugging-задач.
- Используй Haiku для простых изолированных правок, если он доступен.
- Не создавай дублирующие компоненты и не переписывай рабочий код без необходимости.
- Не запускай повторно одинаковые проверки, если код и условия не изменились.
- Не скрывай ошибки и не выдавай mock за production-интеграцию.
