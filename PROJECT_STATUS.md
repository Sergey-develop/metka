# METKA — статус проекта

Обновлено: 2026-10-15

## Архитектурные решения
- [ADR-001](docs/ADR-001-building-recognition.md): одна ONNX-эмбеддинг-модель для iOS/Android/web, кандидаты сужаются геолокацией, решение о награде принимает сервер (pgvector + PostGIS).
- [ADR-002](docs/ADR-002-server-game-logic.md): игровая логика — транзакционные Postgres RPC (SECURITY DEFINER), не Edge Functions.
- Стек: Vue 3.5 + TS 6 (strict) + Vite 8 + Pinia 4 + Vue Router 5 + SCSS, шрифт Inter (локально, @fontsource-variable/inter; как в Figma), Capacitor 8, MapLibre 6, Supabase JS 2, onnxruntime-web 1.30. TS 7 не используется: vue-tsc пока его не поддерживает.
- Районы = территории (отдельной таблицы `territories` нет).
- Платформенные различия изолированы в `src/services/*` за интерфейсами; выбор реализации — в `src/app/providers/services.ts`.

## Важные файлы
- БД: `supabase/migrations/` (схема + RPC), `supabase/seed.sql` (только dev).
- Регистрация: `src/features/auth/` (`ConfirmView`, `ProfileSetupView`, `RegistrationSteps`), RPC `complete_profile_setup` (миграция 004), пиктограммы `src/components/ui/figures.ts`.
- API: `src/services/api/gameApi.ts` (разбор ответов без `any`), `errors.ts` (маппинг, retry).
- Распознавание: `src/services/recognition/` (контракт, качество кадра, ONNX, решение).
- Сканер: `src/stores/scan.ts` (машина состояний), `src/features/scanner/`.
- Вкладки (`src/components/ui/BottomNav.vue`): Главная · Результаты (`src/features/results/`, статистика игрока) · Коллекция · Профиль (аватар, имя, выход) · Задания (временно последняя).
- Моки (только dev): `src/mocks/` — в production-сборку не попадают (проверено).

## Реализовано
Регистрация по шагам: заставка → знакомство → аккаунт (почта или OAuth) → подтверждение (код или ссылка, повторная отправка) → игровой профиль (никнейм + аватар-пиктограмма, `/auth/setup`, обязателен до входа в игру — guard в роутере) → разрешения в контексте (геолокация — пояснение перед системным запросом на карте, камера — при первом скане). Индикатор шагов «Шаг N из 3» в `AuthLayout`. Лоадер — чередование 4 пиктограмм (`FigureLoader`): на заставке под логотипом и в состояниях загрузки. Авторизация (email, восстановление, OAuth по конфигу, deep links, истечение сессии), профиль, карта (bbox-загрузка, районы с прогрессом, позиция, карточки), сканер (полный поток и ошибки), коллекция (поиск, фильтр), задания (прогресс, получение награды), кланы (создание, вступление, выход, рейтинг), лидерборды (RPC), жизненный цикл приложения.

## Не проверено / блокеры
- **Модель распознавания отсутствует.** Нет обученной модели и эталонных эмбеддингов реальных зданий. В production сканер честно показывает «распознавание недоступно». Нужны датасет и оценка по критериям ADR-001.
- **Код подтверждения почты** не проверен на реальном Supabase: шаблон письма «Confirm signup» должен содержать `{{ .Token }}` (см. README); `verifyOtp` с `type: 'email'`.
- **Supabase подключён частично (2026-10-16):** проект и ключи в `.env`, миграции 001–002 применены; **003 (`moscow_districts`), судя по прямоугольным районам на карте, — нет; 004 (`profile_setup`) — нет**: `profiles.avatar_key`/`setup_completed_at` и RPC `complete_profile_setup` отсутствуют → загрузка профиля падает 400. CLI не установлен.
- **Аватары кланов (миграция 005, не применена):** Storage-бакет `clan-avatars` (публичное чтение, ≤512 КБ, WebP/JPEG), загрузка/удаление только лидером в папку своего клана (RLS, проверено в PGlite с эмуляцией Storage). **Нет модерации** — картинки видны всем игрокам; нужна до публичного релиза (жалобы/ручная проверка/автомодерация). При удалении клана файл аватара остаётся в бакете (удалить из SQL нельзя) — нужна периодическая очистка.
- **Android-сборка:** нет Android SDK и JDK 21 (есть только Java 8). Gradle не запускался.
- **iOS-сборка:** нет Mac и Xcode.
- Не проверено на устройствах: камера, GPS, возврат из фона, deep links.
- Конкурентные гонки при приёме скана защищены UNIQUE-ограничениями, но многопоточный тест невозможен в PGlite (одно соединение).
- Каталог: seed — dev-данные (приблизительные координаты зданий). Границы 12 округов — реальные (OSM, миграция 003). Production-каталог зданий не подготовлен.
- Тайлы: по умолчанию OpenFreeMap; условия production-использования нужно подтвердить.
- `npm audit`: 3 moderate в dev-зависимости `@capacitor/cli` (uuid через xcode); в runtime-бандл не входит.
