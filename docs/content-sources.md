# Источники контента каталога

Фото зданий — Wikimedia Commons, свободные лицензии. Пережаты в WebP 1280px без EXIF и лежат в бакете Storage `building-photos` как `<файл>.webp` (миграция 016).
Тексты описаний написаны для METKA по открытым фактам (архитектор, годы, история); у жилых домов — только данные OSM (серия, год, этажность, квартиры, организации).

**Лицензии CC BY / CC BY-SA / FAL требуют указывать автора и лицензию рядом с фото.** В приложении подписи пока нет — нужна до публичного релиза (или заменить фото своими).
