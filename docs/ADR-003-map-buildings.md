# ADR-003: карта с контурами зданий

Статус: принято 2026-10-18 (подложка — по решению владельца продукта).

## Решение
Три независимых слоя:
- **A. Подложка — Яндекс Maps JS API v3** (MapLibre + OpenFreeMap удалены). Код карты за интерфейсом `MapService` (`src/services/map/`); POI и 3D-здания подложки скрыты кастомизацией. Только официальный API; тайлы и данные Яндекса не сохраняем и не извлекаем.
- **B. Геометрия зданий — OpenStreetMap**, своя таблица `osm_buildings` (PostGIS, `geometry(MultiPolygon, 4326)`, GiST). Яндекс не отдаёт геометрию зданий, а хранить полученные через API данные запрещено условиями, поэтому контуры берём только из OSM (ODbL, атрибуция «© OpenStreetMap» обязательна).
- **C. Игровые объекты — таблица `buildings`** (существующий каталог; на неё ссылаются сканы, открытия, эмбеддинги). Связь `osm_building_id` (unique FK), статус `publish_status`: `draft | published | unavailable | hidden`. `is_active` вычисляется триггером (`= published`), поэтому прежние RPC не менялись.

## Доставка данных
- `osm_buildings_in_bbox(bbox, zoom, limit)` → GeoJSON FeatureCollection + `truncated`. bbox ≤ 0.1°, лимит ≤ 3000, упрощение `ST_SimplifyPreserveTopology` до ~½ пикселя на данном zoom, игровые здания идут первыми (обрезаются только обычные контуры). Черновики игрокам не видны.
- Замер на реальных данных Варшавской (1171 здание, PGlite): z16 — 153 объекта / 48 КБ, z14 — 1171 / 342 КБ.
- При росте каталога — векторные тайлы (`ST_AsMVT`; в PGlite недоступно, на Supabase — да).

## Импорт
`npm run osm:fetch` (Overpass → GeoJSON) → `npm run osm:import` (валидация в `tools/osm-import/geojson.ts`, upsert по `(osm_type, osm_id)` через `import_osm_buildings`, только service role). Повторный импорт идемпотентен и не трогает `buildings`. Дубликаты: по id (последний побеждает) и по совпадающему контуру (в файле и в БД).

## Права
Клиент только читает `osm_buildings`. Каталог меняют только админы (`app_admins`, вручную через SQL) через `admin_save_game_building` / `admin_set_game_building_status`.

## Риски подложки Яндекса (открыты)
- Условия JS API описывают использование в браузере; для мобильных приложений Яндекс предлагает MapKit. Работа в WebView (Capacitor: `capacitor://localhost`, `https://localhost`) и ограничение ключа по Referer не подтверждены — проверить на ключе до разработки UI.
- Бесплатная лицензия: логотип/копирайты/«Открыть в Картах» всегда видимы, суточный лимит, хранение данных API запрещено. Коммерческая игра — уточнить нужный тариф.
- Производительность сотен полигонов `YMapFeature` в WebView — замерить на устройстве; запасной вариант — MapLibre (уже был в проекте).
