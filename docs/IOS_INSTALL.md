# «Метка» на iPhone без Mac

Сборка — на облачном Mac GitHub (GitHub Actions), установка — с Windows через Sideloadly и бесплатный Apple ID.
С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить (шаг 4 ещё раз).

## 1. Один раз: настройки в GitHub

Репозиторий → Settings → Secrets and variables → Actions → вкладка **Variables** → New repository variable:

| Имя | Значение |
|---|---|
| `CAP_SERVER_URL` | адрес сайта: `https://sergey-develop.github.io/metka/` (GitHub Pages; Netlify больше не используется — кончились кредиты) |
| `VITE_SUPABASE_URL` | как в `.env` |
| `VITE_SUPABASE_ANON_KEY` | как в `.env` (публичный ключ, не service_role) |
| `VITE_YANDEX_MAPS_API_KEY` | как в `.env` |

Приложение показывает сайт с `CAP_SERVER_URL`: карта Яндекса работает, потому что ключ разрешён для домена сайта,
а обновления сайта сразу видны в приложении без пересборки. Без интернета приложение не откроется.

## 2. Собрать приложение

Репозиторий → **Actions** → «iOS build (unsigned .ipa for sideloading)» → **Run workflow**.
Через 10–20 минут внизу страницы запуска появится артефакт **Metka-ipa** — скачайте и распакуйте, внутри `Metka.ipa`.

Бесплатный тариф GitHub для приватного репозитория даёт около 200 минут облачного Mac в месяц (~10–15 сборок).
Пересобирать нужно только при изменениях нативной части; изменения сайта приходят сами.

## 3. Один раз: подготовка Windows и iPhone

1. Установите **iTunes** с сайта Apple (не из Microsoft Store) — нужен драйвер для iPhone.
2. Установите **Sideloadly** — https://sideloadly.io
3. iPhone подключите кабелем, на телефоне нажмите «Доверять этому компьютеру».
4. iOS 16 и новее: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).

## 4. Установить

1. Запустите Sideloadly, перетащите `Metka.ipa` в окно.
2. Выберите iPhone, введите Apple ID (лучше отдельный, не основной) → **Start**, введите пароль и код подтверждения.
3. На iPhone: Настройки → Основные → **VPN и управление устройством** → ваш Apple ID → **Доверять**.
4. Откройте «Метку», разрешите геолокацию и камеру.

Через 7 дней приложение перестанет запускаться — повторите шаг 4 (сборку повторять не нужно, если нативная часть не менялась).

## Ограничения

- Вход по почте и паролю работает. Ссылки из писем (подтверждение, сброс пароля) и вход через сторонние сервисы
  требуют адреса `app.metka.game://auth/callback` в Supabase → Authentication → URL Configuration → Redirect URLs.
- Фоновое исследование (туман открывается с телефоном в кармане) — следующий шаг: нужен нативный модуль
  фоновой геолокации и разрешение «Всегда».
